# Scoped native build-script reuse

The local generator `benchmarks/experiments/build_script_execution/native_contract.py` extends the existing ring/SQLite contract with media 0.1.0 and tree-sitter 0.26.11. It targets the actual native Apple ARM Harness configuration, default native flags and SDK selection. It is an explicit caller declaration, not automatic proof that arbitrary Rust scripts are hermetic. Alternate native flags, tool/include overrides and unsupported features fall back to normal execution.

Media's audited script runs xcrun, bindgen and rustfmt over its private source header and Apple framework headers. The generated contract includes the SDK framework tree, libclang, native compiler resources, physical rustfmt, a formatter wrapper and fixed formatting config. The separate bindgen tool JSON chooses libclang, clang and rustfmt identically for direct, Nano and kache. These shared controls change tool discovery; the fixture requires generated output bytes/modes to match the original selection.

Tree-sitter's audited core script copies `stdlib-symbols.txt` and compiles bundled C sources using cc. The contract captures the complete package, default native toolchain resources, and rejects wasm/bindgen feature variants or overridden compiler flags. Grammar crates and C++ helpers are not covered by this candidate yet.

Run the generator with a frozen Nano binary and actual Harness project, using new private paths for `--tools-state`, `--output` and `--env-output`. Its output includes preparation hashes. Pass the contract and tool JSON to `tests/native_script_execution.py` with the full verbose Cargo log, independently retained direct artifact reference directory, a new `--state`, and `--output`. The runner verifies the retained real executables against their reference manifest, then executes them in private package copies.

The fixture checks original versus explicit tool output equality, direct/cold/three-hit equality, preserved-mtime edits and reverts, compiled runtime behavior, guarded overrides, failure propagation and corruption repair. The media edit adds an allowlisted macro to the actual input header and verifies its generated Rust constant at runtime. The tree-sitter edit changes the existing null-language setter result and verifies the linked native library's result before and after reverting. Media's formatter failure follows bindgen's own nonfatal fallback behavior; an invalid-header case separately checks its fatal exit. Raw stdout/stderr remain retained; normalized equality excludes Nano diagnostics and nondeterministic Rust panic thread IDs.

Isolated script timings are diagnostics, not project speed claims. Before accepting a broader optimization, require a completed full-Harness capture with unchanged sources, own-cold output bytes/modes and CLI probes, then repeated alternating untraced comparisons against kache and actual full application source edits. Preserve exact binaries, tool JSON and contract hashes. Keep failures separate and reject invalidation or artifact regressions.

The [completed local fixture](../benchmarks/harness-native-script-fixture.json) records 22 media and 17 tree-sitter executions with all gates passing. Three restored-hit medians are 0.103 s media and 0.038 s tree-sitter in this isolated session; explicit direct executions are 2.267 s and 1.762 s respectively. These timings do not establish whole-build or cold-build improvements. The exact frozen binary and runner hashes are retained in the report.

# Large Rust metadata snapshots

The full Harness capture identified `objc2_app_kit` as a warm recompile: native-link auditing ended with `StreamTooLong` on its 117,444,601-byte `.rmeta`. Small sources, manifests and cache-entry readers retain their existing 64-MiB limit. Metadata snapshots have a separate 512-MiB bound, require a regular file and verify recorded length, inode, kind, mtime and ctime after reading. Oversized or changed files retain refusal.

Metadata's lazy tables require random access, so this implementation owns a bounded snapshot rather than memory mapping a file that could truncate during reading. Graph decoding and native-link auditing reuse the same snapshot when decoding succeeds. All full content hashing, version checks, native-kind refusal, lookup membership and output validation remain active. The read limit is exclusive in Zig 0.17; the reader permits one extra byte for EOF and then requires the exact recorded length.

[The first actual compiler replay](../benchmarks/harness-large-metadata-replay.json) verifies identical `.rlib`, `.rmeta` and dep-info bytes across accepted compilation, candidate compilation and candidate restoration. The accepted binary declines storage; the candidate restores in 0.166s. [An independent-output replay](../benchmarks/harness-large-metadata-independent-replay.json) verifies the final candidate binary and restores in 0.171s. These are diagnostic single samples, not whole-project or cold-speed claims. The latter replay overlapped the direct prime of a subsequent full comparison; wrapper measurements start after it finishes. Source hashes remain unchanged.

The [replay runner](../benchmarks/experiments/large_metadata_replay.py) consumes a private recorded compiler invocation and the matching Cargo environment extracted from the complete console. It uses a new state/output/cache directory. Raw argv and environment records stay private. Its output records binary, invocation, source and artifact hashes.

The large-file unit check crosses the old 64-MiB bound and rejects an oversized sparse file before allocation. Native metadata cache checks retain dynamic/framework behavior, hidden static/macro refusal, actual native execution, preserved-mtime source invalidation and another-compiler refusal. Rust/Zig integration and ordinary producer restore checks pass. A full untraced Harness comparison is running under `/tmp/nano-full-harness-large-metadata-20261011`; whole-project effects remain pending.
